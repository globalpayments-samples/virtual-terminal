MOTO Virtual Terminal

Keyed-entry card payments for Mail Order / Telephone Order. The agent takes the card details over the phone or by mail and charges them here.

Why MOTO? This charge is sent with entry_mode = MOTO, which tells the network the cardholder is not present at a browser. MOTO transactions are out of scope for SCA/3-D Secure, so no challenge flow is triggered. Tick the box below to also store the credential (COF) for future merchant-initiated payments.

Two MOTO flows

Both post to /process-payment.

  1. Standard MOTO A one-off keyed charge. Nothing is stored.
  2. MOTO + Credential on File The same charge plus a stored-credential block. The response returns a brandReference you persist to initiate later MITs.
