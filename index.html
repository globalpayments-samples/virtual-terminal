MOTO Payments — GP-API Sample

A Global Payments sample project demonstrating Mail Order / Telephone Order (MOTO) payments via GP-API. An agent-facing virtual terminal keys in a card, the server charges it with entry_mode = MOTO — exempting it from SCA/3DS2 — and can optionally store the credential (COF) for later merchant-initiated charges.

What is MOTO? Mail Order / Telephone Order transactions are entered by an agent on behalf of a customer (phone, IVR) rather than typed by the cardholder. Correctly flagged MOTO transactions are out of scope for Strong Customer Authentication under PSD2. See the GP-API MOTO documentation.
